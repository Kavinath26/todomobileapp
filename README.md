##Focus

Focus is a productivity-oriented Android mobile application built with React Native CLI and Firebase Authentication. It provides secure user login through Email/Password and Google Sign-In. This repository shares information about the app and its APK release, but does not include the full project source code.

##Description

Focus is designed to help users stay organized and maintain better productivity. The app offers a clean interface, fast performance, and simple, secure authentication powered by Firebase. Users can log in quickly using their preferred method and begin using the app immediately.

##Authentication Details

Focus uses Firebase Authentication to ensure secure and reliable login options. Supported login methods:

Email and Password

Google Sign-In

All authentication is handled securely through Firebase services.


##Privacy and Security

Passwords are never stored in the app.

Authentication is handled directly by Firebase.

No sensitive information is exposed or shared.

Only essential data required for login is processed.
